## 🌟 `new_folder_3` / `folder_3` — Design 3 Full-Width Suite

All pages are styled strictly according to the reference mockup with:
- **Full Width Edge-to-Edge Architecture**: `max-width: 1650px !important; width: 100% !important; padding: clamp(20px, 4vw, 70px) !important;`
- **Original Content & Imagery**: Every single page retains the full copy, course syllabi, FAQs, testimonials, mentors, and addresses from the live site.
- **Header & Navbar UI**: White sticky navbar, Navy `#0d47a1` active pill, Red `#e11d48` "Admission Open 2026" CTA, and "DOWNLOAD NOW" PDF badge.
- **Footer**: Deep navy background with the Mumbai skyline silhouette and complete links.
